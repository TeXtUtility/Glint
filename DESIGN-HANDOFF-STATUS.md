# Overlay redesign: what's built and what's left

The design handoff is in `design/overlay-handoff/` (open `Glint Overlay Redesign.dc.html` in a browser; `README.md` summarises every artboard). This file checks each artboard against the code on `beta` at `11bb69f` and lists everything still to build, with the exact values from the design, so each item can be built without reopening it. Direction **1a Island** was chosen; **1b Edge column** and **1c Orb** are not being built.

Values are for the dark theme. Settings and onboarding also follow Light: build the dark values here and a light twin from the Settings light palette (`styles.css`, the `html[data-route="settings"]` tokens). Material Symbols names in the design are placeholders for Glint's own icons (`icons.tsx`).

## Keep as built: deliberate changes from the design

These differ from the design on purpose. Don't "fix" them back.

- **Invisible edge** is 1.5 px dashed `rgba(154,169,255,.95)` with a 3 px `rgba(123,143,255,.14)` halo, not 1 px dashed `rgba(123,143,255,.6)`, on every surface including Glance and the panel (`98a670d`, `266c34f`). Any mock that shows the design's edge (5b's capsule, 3b, 4h) follows the code.
- **No "Visible on share" chip.** The solid edge and the ringed eye say it (`98a670d`).
- **Smart lives only as the bulb by Send.** No labelled Smart pill on the capsule (`98a670d`).
- **Capsule idle and paused buttons are icons:** Start is a mic circle, Resume a history circle, the paused Resume a play circle in the accent tint (`98a670d`).
- **The capsule has a chat-box button** (opens the panel with the cursor in the input) and a divider before it, shown in failure too (`98a670d`).
- **Layout is Full / Glance / Ghost.** Ghost shares Glance's corner and strip (`99af8f6`, `e7d2ce6`).
- **Meeting options ends with "All settings…"** and its shortcut (`11bb69f`).
- **Glance asks always use the fast model**, so the Glance card never shows the smart/Opus variant (`99af8f6`).
- **Settings General** has an "Asking" section (screenshot, note text, position, copy replies); Overlay also holds Ghost's typing permission, Invisible and Discreet; Mac has an Updates row (`266c34f`).
- **Updates never cut off a call:** install is disabled during a live session and a ready update waits for it to end (`8bde526`, `f8e4c22`). The design's "A live session resumes where it stopped" copy doesn't apply.
- **Saved API keys never show, not even a tail** like "sk-ant-…4f2a" (`266c34f`).
- **Shortcuts are grouped** (During a call, Overlay, Ghost, In the chat panel), and move and scroll are separate recordable rows (`266c34f`). **Modifiers are written in Mac order**, ⇧⌘\ not ⌘⇧\ (`beaae98`).
- **Menu bar:** the mode and "Ends the session" are native sublabels, not right-aligned text (`beaae98`).
- **Modes note label** says the mode's note is drawn under the note from General (it's added, not swapped in), not "overrides the global note" (`8928b7f`).
- **Voice page** has a Room mode switch (`266c34f`).
- **Onboarding follows Light/Dark** and paints its background first (`11bb69f`).

## Needs a decision

1. **Glass blur.** The design's `blur(24px)` behind the capsule, panel, tray and Meeting options needs macOS vibrancy clipped to each rounded surface (CSS `backdrop-filter` can't see other apps through a transparent window, and whole-window vibrancy would show in the transparent margins). Build it natively via `mac-panel.ts` (an `NSVisualEffectView` per surface), or leave the flat glass?
2. **Guess before asking.** The design shows "✦ Guess: Priya Shah" as soon as the "Who's Speaker 2?" tray or the speaker menu opens. That costs one AI call per prompt. Guess up front, or keep Guess as a button?
3. **Sample call audio for Try it (5b).** It needs a bundled ~48 s recording of "Jordan" asking two questions, played through the speakers so the real capture transcribes it. Record one, or generate it with text to speech?
4. **Template tips (5c).** The handoff has one tip (Behavioural: "add your CV as a reference file so answers draw on your real projects"). The other 10 need writing.
5. **3c "By date" grouping** isn't drawn. Suggested: Today / Tomorrow / "Fri 2 Oct" / No date / Done, with rows showing the owner pill instead of the date.
6. **A "Notes ready" notice** that opens the Follow-up window when a session's notes finish. Implied by 3c but not drawn.
